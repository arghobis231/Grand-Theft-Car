# Grand Theft Car

A retro-style top-down highway racing game for Android.

In **Grand Theft Car**, you drive against the traffic on a fast-paced highway while avoiding incoming vehicles, surviving increasingly difficult stages, and escaping the police after a crash.

## 🎮 Game Features

* 🚗 Top-down retro racing gameplay
* 🛣️ Six-lane highway
* 🚘 Multiple types of traffic vehicles
* 🚔 Police chase after crashes
* ⚡ Increasing speed and difficulty
* 🌆 Multiple environments and scenarios
* 🌙 Day, sunset, night, and weather-based stages
* 🏆 Score and survival-based gameplay
* 💥 Collision and near-miss mechanics
* 🎵 Game audio and sound effects
* ⚙️ Settings for gameplay and audio
* 📱 Designed for Android devices

## 🏁 Stages

The game features five stages, with each stage introducing a different environment and increasing difficulty.

| Stage | Environment    | Setting |
| ----- | -------------- | ------- |
| 1     | City Highway   | Day     |
| 2     | Countryside    | Sunset  |
| 3     | Mountain Road  | Night   |
| 4     | Desert Highway | Storm   |
| 5     | Neon City      | Night   |

As the stages progress, the game becomes faster and more challenging.

## 🎯 Gameplay

The objective is simple:

**Drive against the traffic and survive as long as possible.**

Change lanes to avoid incoming vehicles. As your speed increases, your reaction time becomes shorter and the traffic becomes more challenging.

If you crash, a police car arrives and begins a pursuit.

Survive the stage to reach the tunnel and complete the stage.

## 🚀 Getting Started

### Requirements

* Android Studio
* Android SDK
* JDK compatible with the project's Gradle configuration
* Android device or emulator

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/arghobis231/Grand-Theft-Car.git
```

2. Open the project in **Android Studio**.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Run the application.

### Build APK

In Android Studio:

```text
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

The debug APK will normally be generated at:

```text
app/build/outputs/apk/debug/app-debug.apk
```
